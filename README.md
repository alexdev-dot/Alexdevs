# AlexDevs - Project 1 (Modern Portfolio)

Welcome to **Project 1**, a professional, modern portfolio website designed to showcase web development skills, projects, and services. This project features a sleek dark theme with neon cyan and magenta accents, ensuring a premium user experience across all devices.

## 🚀 Features

- **Modern UI/UX Design**
  - **Dark Mode Aesthetic**: A professional deep slate background (`#0f172a`) with vibrant neon highlights.
  - **Glassmorphism**: Stylish semi-transparent cards and headers.
  - **Smooth Animations**: Scroll reveals, hover effects, and interactive elements.

- **Responsive Layout**
  - Fully optimized for Desktop, Tablet, and Mobile devices.
  - Custom media queries for grids and navigation.

- **Comprehensive Pages**
  - **Home**: Hero section with typing effect, About preview, Skills, and Mission.
  - **About Me**: Detailed biography, experience timeline, and tech stack utilization.
  - **Projects**: Portfolio gallery with hover effects and links.
  - **Testimonials**: Client feedback section.
  - **Contact**: Availability card and contact form layout.
  - **Legal**: Privacy Policy and Terms of Service pages.

- **Authentication Mockups**
  - Login, Register, and Forgot Password pages with a dedicated design.
  - User Dashboard template.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for SEO and accessibility.
- **CSS3**:
  - CSS Variables for consistent theming.
  - Flexbox & Grid for layout.
  - Keyframe animations and transitions.
- **JavaScript (Vanilla)**:
  - Mobile Menu toggling.
  - Scroll reveal animations (Intersection Observer).
  - Dynamic skill bars and functionality.
- **FontAwesome**: For scalable vector icons.
- **Google Fonts**: Poppins and Inter for modern typography.

## 🚀 How to Run Locally

1. **Clone the Repository**
   ```bash
   git clone https://github.com/alexdev-dot/Project-1.git
   ```

2. **Navigate to the Project Directory**
   ```bash
   cd Project-1
   ```

3. **Open the Website**
   - Simply open `frontend/index.html` in your preferred web browser.
   - Alternatively, use VS Code's "Live Server" extension for the best experience.
